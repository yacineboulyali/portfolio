# InfoLab — Unité 1

Projet pédagogique statique original, inspiré d’une organisation par activités mais **sans reprendre le code, les textes ou les images d’un tiers**.

## Technologies
- HTML5
- CSS3
- JavaScript vanilla
- localStorage
- Aucun framework, aucun backend

## Fonctions
- 22 activités interactives
- ouverture dans la même page
- navigation précédent / accueil / suivant
- illustrations SVG originales stockées dans `assets/`
- QCM, associations, classifications, ordre, réponses textuelles et défi de vocabulaire
- progression et meilleur score enregistrés localement
- responsive mobile / desktop

## Publication GitHub Pages
1. Créer un dépôt GitHub.
2. Décompresser et envoyer tous les fichiers à la racine.
3. `Settings > Pages > Deploy from a branch`.
4. Choisir `main` et `/root`.

Le site fonctionne aussi en ouvrant simplement `index.html` dans un navigateur moderne.
